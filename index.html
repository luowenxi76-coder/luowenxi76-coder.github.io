代表作品 01：VoxRadio — macOS 私人 AI 电台播放器

独立产品设计 & Vibe Coding · 2026.04 – 2026.11

让 AI 安静地嵌入听歌习惯，而不是把控制台铺在用户脸上

原生 macOS SwiftUI + Apple MusicKit + 本地 VoxCPM2 TTS Sidecar + 14 种编码 Agent Hooks
246 Commits SwiftUI + Python VoxCPM2 14 Agent Hooks

早期踩坑（为什么推倒重构）

  • 面壁校园黑客松初版把 TTS 队列、sidecar 状态和模型日志全铺在首页。
  • 像一个炫技的“工程调试面板”，但每天打开听歌时视觉噪点太高。

收敛后的 4 层极简架构

  • 对标 Spotify / Apple / ElevenLabs / Raycast / Linear 撰写完整设计规范。
  • 首页仅保留：Now Playing 主卡 → 临时模式 Daily Opening → Apple Music 搜索 → 小型 Text DJ；诊断与日志全部收进 Settings。

个性化 Daily Opening 闭环

  • 联动 Open-Meteo 天气 + EventKit 当日日历/提醒（先摘要成短句再喂给 TTS）+ 本地 V1 SQLite 音乐偏好记忆。
  • 由本地 VoxCPM2 TTS Sidecar 合成早间播报，播完无缝切入 Apple Music 真实播控。

工程可用性与降级兜底

  • 提供不下载模型的 Mock TTS 与本地 WAV 演示链路，确保零依赖快速验收。
  • Codex DJ provider 异常时保留快捷播控并清晰提示降级，配套 Swift XCTest 与 Python 侧自动化校验。

Dev Companion 编码陪伴场景

  • 通过统一 Python Hook 入口与 Plugin Bridge，适配 14 种主流编码 Agent。
  • 听歌同时低干扰感知外部 Agent 的 running / needs attention / failed / completed 状态。

严格的 Receive-Only 安全边界

  • 明确坚持只读原则：不审批请求、不反向分发 prompt、不执行外部工具。
  • 本地认证 secret 由服务管理器托管，配置中零明文密钥；显式代理拒绝明文推理 URL 并校验 TLS。
