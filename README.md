# 罗文希 · LUO WENXI — Interactive Portfolio

Live Site: https://luowenxi76-coder.github.io/  
MoliPulse Proof Report: https://luowenxi76-coder.github.io/molipulse.html

## Tech Stack

- **React 19** + **TypeScript** + **Vite 6**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Framer Motion** (scroll-linked reveal, role-lens spring physics, command palette transitions)
- **HTML5 Canvas** (interactive 3D halftone dot-matrix wave + draggable 3D wireframe DevRel globe)
- **GitHub Actions** (`actions/deploy-pages`) auto-deployment to GitHub Pages

## Development

```bash
npm install
npm run dev
npm run build
```
